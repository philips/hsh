# hsh Website

Source for the hsh static website deployed to https://hsh.ifup.org via GitHub Pages.

## Development

```bash
npm install
npm run dev
npm run build
```

## Structure

- `src/pages/` - Astro pages
- `src/layouts/` - Layout components
- `src/styles/` - Global CSS
- `public/` - Static assets (logo, CNAME)

See SETUP.md for deployment details.
