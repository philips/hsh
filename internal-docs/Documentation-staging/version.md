# hsh version

The `hsh version` command prints the hsh version. The command also prints the
git commit and the build platform.

## Print the version

Type the command. The command prints one line.

<!-- tape:run sleep=1s -->
```sh
hsh version
```
<!-- tape:wait /hsh/ -->

<!-- tape END -->

## Reference

Usage:

```
hsh version
```

The command takes no flags other than `-h, --help`.
